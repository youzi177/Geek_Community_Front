> Fluff 轻羽社区 - 下一代社区平台

FlyNext 是 Fluff 轻羽社区的开源项目代码仓库。

面向用户的产品名称：**Fluff 轻羽社区**

面向开发者的项目名称：**FlyNext**

## 🚀 简介

`FlyNext`是一个基于Fly社区模板开发的社区项目，采用了目前最新的主流框架Vue3.5，同时也是一个前后端分离，多平台的项目，这也是`FlyNext`名字的由来，在Web前端采用Fly社区的模板，而在其他平台则完全采用不同开发技术开发，业务上基于前端来开发。下面是关于各平台采用的技术找，前端使用Vue3+Laui+，后端使用koa+mongo+redis，移动端采用Flutter3.x，小程序使用UniappX，管理后台使用Vue3+Naive

## 🚀 快速开始

### 环境要求

- Node.js ≥ 24（推荐24.15.0）

### 本地开发部署

> 本项目由多个独立仓库组成，各端需要使用对应版本才能保证接口、数据结构和业务逻辑兼容。
>
> ⚠请勿直接使用不同时间拉取的最新代码进行组合，建议使用相同版本号的代码。

|  系统模块  |      仓库       | 当前稳定版本 | 兼容后端版本 |
| :--------: | :-------------: | :----------: | :----------: |
|  Web 前端  |  FlyNext-Front  |    v1.0.0    |    v1.0.x    |
| App 客户端 | FlyNext-Flutter |    v1.0.0    |    v1.0.x    |
| 微信小程序 | FlyNext-UniAPPX |    v1.0.0    |    v1.0.x    |
|  管理后台  |  FlyNext-Admin  |    v1.0.0    |    v1.0.x    |
|  后端服务  |   FlyNext-koa   |    v1.0.0    |      -       |
